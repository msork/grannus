# Contributing

Read `AGENTS.md`, `PROJECT_SETTINGS.md`, and the relevant architecture/protocol
documents before editing. Start with an issue for architecture, protocol,
hardware-support, dependency, or licensing changes.

Use focused conventional commits. Every PR must describe scope, tests, security
impact, latency impact, supported hardware actually tested, truth-label changes,
and remaining risks. Run `just check` or the equivalent Cargo commands.

By contributing, you certify that you have the right to submit the work under
the MIT License. Do not submit copied GPL implementation, proprietary material,
firmware, keys, ROMs, or unsanitized captures. Protocol research must record
sources and licenses and distinguish observed facts from derived implementation.
